## 4. Как использовать

Для больших задач делегировать независимый анализ, сохраняя основную реализацию у одного владельца. Для небольших правок использовать только релевантный навык и минимальную проверку.

Пользовательские инструкции и актуальный [дизайн-бриф](portfolio-design-brief.md) имеют приоритет перед общими рекомендациями навыков. В частности, округлые CTA и компактный ряд из трёх проектов допустимы: они соответствуют выбранному референсу.

Проверка действительна для текущей сессии и файлов на указанную дату. После переноса проекта или изменения конфигурации повторить валидатор; при необходимости выполнить одну небольшую задачу с соответствующей ролью.
