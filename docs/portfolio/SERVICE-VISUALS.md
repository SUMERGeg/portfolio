# Визуализация услуг

Добавлено 2 октября 2026 года по запросу пользователя: показывать смысл услуг через изображения.

Три иллюстрации созданы встроенным `image_gen` и сохранены в проект:

- `src/assets/services/creation.png` — каркас → готовый сайт → мобильная версия.
- `src/assets/services/redesign.png` — перегруженная страница → обновлённая подача.
- `src/assets/services/extension.png` — существующий сайт → дополнительные страницы.

Это иллюстрации услуг, не скриншоты клиентских проектов. Исходники 1536 × 1024; Astro Image создаёт WebP 320/640/960 px с ленивой загрузкой. Общий компонент `src/components/ServiceVisual.astro` используется на главной и `/services/`, содержит alt и поясняющую подпись. На мобильной главной изображение располагается под описанием.

Полные финальные промпты: [service-illustration-prompts.json](media/service-illustration-prompts.json). Проверка типов — 0 ошибок / 0 warnings, две прежние подсказки; сборка девяти страниц успешна. Обе страницы проверены на 1440/1024/768/390 без горизонтального переполнения; все три изображения страницы услуг загрузились, ошибок браузера нет. [Измерения](media/services-layout-checks.json), [главная desktop](media/services-home-1440.jpg).
