# Задание для Figma — портфолио Егора Данилова

Подготовить макеты русскоязычного портфолио «Егор Данилов — сайты для бизнеса» по актуальным документам. Это задание, а не подтверждение существующих макетов.

## Основное направление

Почти чёрный фон, светлая геометрическая типографика, электрический синий акцент. Крупный оффер слева, ноутбук с автомобильным NOIR справа, локальное мягкое свечение. Округлые CTA и компактный проектный ряд соответствуют пожеланию пользователя.

Hero: «Сайты для бизнеса, которые работают». Синим выделить «работают». Описание и действия взять из контентного документа.

Подпись: «NOIR / Сайт автодетейлинга / Концептуальный проект». Нельзя переносить лампу из референса как изображение этого кейса.

Проектный ряд: NOIR, СЕЗОН, Lost&Found. Не использовать Kraft, Altai Travel, Pure, примерные годы или показатели «3+ / 20+ / 100%».

## Макеты

1. Основы: цвета, типографика, интервалы, CTA и состояния фокуса.
2. Главная: desktop 1440 и mobile 390.
3. Адаптации главной: 1024 и 768 с отдельной композицией.
4. Список проектов и три кейса.
5. Услуги, об авторе, контакты, мобильное меню и 404.

Главная ниже проектов: услуги → четыре шага процесса → краткий About → контактный CTA → подвал. Референс не показывает эти секции, поэтому проектировать их в том же языке, без повторяющихся тяжёлых контейнеров.

Использовать Auto Layout и текст в обычном потоке. Не фиксировать высоты блоков с длинными русскими текстами. На 390: текст → CTA → ноутбук → подпись; проекты по одному. На 768 допустим крупный NOIR и два проекта ниже парой.

## Контент и ресурсы

Годы, опыт, роль, стек и контакты брать только из подтверждённых материалов. Пока нет готового мокапа или скриншота, обозначать слой как рабочий визуальный placeholder, а не как финальный кейс.

Макеты должны содержать читаемые тексты, нужные состояния меню и понятные связи между страницами. Эффекты — дополнение; взаимодействие доступно и без них.
