## Роли при выполнении

Основной агент отвечает за решения и согласованность документов. Для независимых задач использовать профильных агентов: архитектура, арт-дирекшн, UX; после реализации — responsive QA и проверка доступности. Одному исполнителю назначать конкретный набор файлов.

Не запускать полный состав агентов после каждого изменения. Проверки проводить по масштабу задачи и останавливаться после выполнения требований.
